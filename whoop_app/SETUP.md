# Setup

The Dart sources are here; the iOS/macOS platform folders are generated by Flutter.

1. Install Flutter (once): `brew install --cask flutter`, then `flutter doctor` and fix what it lists
   (accept the Xcode licence with `sudo xcodebuild -license accept`; `brew install cocoapods`).
2. Generate the platform projects, from this folder:

       flutter create --platforms=ios,macos --org com.giuseppescaffidi .
       flutter pub get

3. Bluetooth permissions (Flutter's templates do not add them):
   - `ios/Runner/Info.plist` and `macos/Runner/Info.plist` — add
     `<key>NSBluetoothAlwaysUsageDescription</key><string>Connects to your WHOOP strap.</string>`
   - `macos/Runner/DebugProfile.entitlements` and `macos/Runner/Release.entitlements` — add
     `<key>com.apple.security.device.bluetooth</key><true/>`
4. Run on the Mac first (real Bluetooth, no phone needed): `flutter run -d macos`.
   The iOS Simulator has no Bluetooth; use a real iPhone for iOS.
5. Quit the WHOOP app on your phone before connecting — the strap accepts one central at a time.
